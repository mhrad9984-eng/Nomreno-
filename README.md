# نمرینو (Namrino)

پلتفرم آزمون‌ساز آنلاین — نسخه Next.js.

این پروژه در حال انتقال از یک آرتیفکت تک‌فایلی به یک پروژه واقعی Next.js متصل به Supabase است (فاز ۴).

## اجرای محلی (فقط برای مرجع؛ روی گوشی لازم نیست)

npm install
npm run dev

## دیپلوی
این پروژه برای Vercel آماده است. کافیست ریپازیتوری گیت‌هاب را در Vercel Import کنید.
